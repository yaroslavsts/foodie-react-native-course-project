# Foodie App — React Native project draft

Browse ten horizontally scrollable categories, read recipe details, favorite/unfavorite, filter My Food and add/edit/delete personal recipes with image upload. Back buttons and native Android back navigation are included. Recipes and favorites persist with AsyncStorage; invalid input is rejected. Sample calories and preparation values are illustrative, not nutritional advice.

Run `npm install` then `npm run web` (web preview) or `npm start` (Expo development build). This draft uses Expo SDK 54/React Native 0.81 and React 19.1. Match your Snack/Expo runtime SDK before import; current Expo Go compatibility must be checked.

Uses bundled illustrations and a local collection, not a live multi-user backend. Public source draft. No app-store release or course submission is performed by this repository.
